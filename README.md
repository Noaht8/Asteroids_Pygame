# Asteroids Pygame

A classic arcade-style space shooter game built using Python and Pygame.

## 🚀 Features

- **Spaceship Movement**: Navigate your ship using `w` `s` `a` `d` keys.
- **Asteroid Destruction**: Shoot and destroy asteroids that break into smaller pieces.
- **Game Over & Restart**: Game ends upon collision; restart by pressing 'Space'.
